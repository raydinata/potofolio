SPK Pemilihan Paket Internet

Sistem pendukung keputusan · Metode SAW

Sistem Pendukung Keputusan (SPK) untuk memilih paket internet operator telekomunikasi terbaik dengan metode Simple Additive Weighting (SAW). Penilaian memakai lima kriteria (segi paket, kecepatan, harga, masa aktif, dan kuota) yang masing-masing punya bobot dan jenis benefit atau cost.

Dashboard menampilkan jumlah provider, kriteria, dan responden, serta peringkat Top 3 provider berdasarkan nilai preferensi. Menu lainnya mencakup data kriteria dan alternatif, matriks normalisasi, rekomendasi untuk konsumen, dan ranking global.

Saya membuat sistem ini menggunakan PHP untuk logika program dan pemrosesan data, CSS untuk tampilan dashboard, serta JavaScript untuk interaksi di sisi pengguna.

  • PHP
  • CSS
  • JavaScript
